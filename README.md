# Мини-приложение «Плеер» для Telegram

Веб-плеер, который открывается внутри Telegram: очередь, поиск, перемотка по волне,
перемешивание, повтор, избранное, подстройка под тему пользователя, управление
с экрана блокировки (Media Session).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё мини-приложение: вёрстка, стили, логика. Зависимостей нет. |
| `tracks.json` | Плейлист. Если файла нет — плеер возьмёт встроенный демо-список. |
| `bot.py` | Бот на aiogram 3: кнопка запуска + кнопка меню. |

## Как поднять за 15 минут

1. **Создайте бота.** В [@BotFather](https://t.me/BotFather): `/newbot`, сохраните токен.
2. **Выложите статику по HTTPS.** Telegram открывает мини-аппы только по `https://`.
   Подойдёт GitHub Pages, Cloudflare Pages, Netlify, Vercel или свой nginx.
   Достаточно положить рядом `index.html` и `tracks.json`.
3. **Зарегистрируйте адрес.** В BotFather: `/newapp` → выберите бота → укажите
   короткое имя и URL. Получите ссылку вида `https://t.me/ваш_бот/player`.
4. **Запустите бота:**
   ```bash
   pip install "aiogram>=3.7"
   export BOT_TOKEN="123456:ABC..."
   export WEBAPP_URL="https://ваш-домен/"
   python bot.py
   ```
5. Откройте бота, `/start` → «Открыть плеер».

### Локальная разработка

```bash
python -m http.server 8080          # отдаём папку
ngrok http 8080                     # получаем https-адрес
export WEBAPP_URL="https://xxxx.ngrok-free.app/"
```
Открыть мини-апп можно и в браузере — он работает и без Telegram,
только избранное тогда хранится в `localStorage`, а не в облаке Telegram.

## Свои треки

Отредактируйте `tracks.json`:

```json
[{ "id": "any-id", "title": "Название", "artist": "Исполнитель", "src": "media/file.mp3" }]
```

`src` — относительный путь рядом с `index.html` или прямая ссылка на файл.
Требования к источнику:

- файл отдаётся по HTTPS;
- сервер поддерживает `Range`-запросы (иначе не будет перемотки) — nginx и
  большинство CDN умеют это из коробки;
- при ссылке на чужой домен нужен заголовок `Access-Control-Allow-Origin`,
  иначе браузер заблокирует загрузку.

Поддерживаемые форматы: mp3, m4a/aac, ogg, opus, wav.

## Что уже учтено

- Тема: цвета берутся из `--tg-theme-*`, светлая и тёмная выглядят одинаково опрятно.
- Кнопка «Назад» Telegram закрывает очередь.
- Хаптик-отклик на нажатия.
- `CloudStorage` хранит избранное, режимы и последний трек — они переезжают
  вместе с аккаунтом на другое устройство.
- Автоплей при старте не запускается: мобильные браузеры его блокируют,
  первый трек стартует по нажатию.

## Куда расти

- **Каталог на бэкенде.** Заменить `fetch('tracks.json')` на запрос к своему API и
  проверять `initData` на сервере (подпись HMAC-SHA256 по токену бота) — без этой
  проверки нельзя доверять `initDataUnsafe.user`.
- **Загрузка треков из чата.** Бот принимает аудио, сохраняет `file_id`, отдаёт
  плееру временные ссылки через `getFile`. Учтите: ссылка живёт около часа.
- **Оплата подписки.** `Telegram.WebApp.openInvoice()` или Stars.
- **Поделиться треком.** `Telegram.WebApp.sendData()` — обработчик уже есть в `bot.py`.

## Про музыку и правила

Telegram снимает мини-аппы с публикации за раздачу чужих фонограмм. Безопасный
вариант — собственный или лицензированный каталог либо файлы, которые пользователь
загружает сам.
